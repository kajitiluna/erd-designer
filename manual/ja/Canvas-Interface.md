# キャンバスインターフェース

キャンバスインターフェースは、エンティティ関係図を設計するメインワークスペースです。このセクションでは、インターフェースで利用可能な各メニューとコントロールの詳細な概要を提供します。

![キャンバスインターフェース概要](../screenshots/main-canvas-interface.png)

## 2.3.1. 各メニューについて

### タイトルパネル

タイトルパネルはインターフェースの上部に表示され、以下が含まれます：

- **ERD Designer ロゴ**: アプリケーションの視覚的識別子
- **図名フィールド**: 現在の図名を表示し、編集を可能にします
- **設定ボタン**（⚙️）: アプリケーション設定と環境設定へのアクセス

### 編集モードパネル

編集モードパネルは左側に配置されており、5つの主要ツールが含まれています：

#### SELECT モード
![選択アイコン](../screenshots/select-icon.png)
- **目的**: 既存の要素を選択・操作するためのデフォルトモード
- **使用方法**: キャンバス上のテーブル、リレーション、メモをクリックして選択
- **機能**: 
  - 単一クリックで個別の要素を選択
  - ドラッグして選択した要素を移動
  - ダブルクリックで要素のプロパティを編集

#### GRAB モード
![グラブアイコン](../screenshots/grab-icon.png)
- **目的**: キャンバスをパンして移動
- **使用方法**: ドラッグしてキャンバス全体の表示を移動
- **使用場面**: 表示領域を超えて拡張された大きな図で作業する際に便利

#### TABLE モード
![テーブルアイコン](../screenshots/table-icon.png)
- **目的**: 新しいデータベーステーブルを作成
- **使用方法**: キャンバスをクリックして新しいテーブルを配置
- **プロセス**: テーブルのプロパティを定義するためのテーブル作成ダイアログが開きます

#### RELATION モード
![リレーションアイコン](../screenshots/relation-icon.png)
- **目的**: テーブル間の関係を作成
- **使用方法**: 一つのテーブルをクリックし、次に別のテーブルをクリックして関係を作成
- **機能**: さまざまなリレーションタイプ（一対一、一対多、多対多）をサポート

#### MEMO モード
![メモアイコン](../screenshots/memo-icon.png)
- **目的**: 図にテキストノートと文書化を追加
- **使用方法**: キャンバスをクリックして新しいメモを配置
- **機能**: カスタマイズ可能なテキスト、フォント、色、サイズ

### アクションパネル

編集モードパネルの下に配置され、追加機能を提供します：

#### 表示スタイル
- **オプション**: 
  - **Physical**: 物理名のみを表示
  - **Logical**: 論理名のみを表示  
  - **Both**: 物理名と論理名の両方を表示（デフォルト）
- **目的**: テーブルとカラム名の表示方法を制御

#### アンドゥ/リドゥコントロール
- **アンドゥ**: 最後のアクションを元に戻す（Ctrl+Z）
- **リドゥ**: 以前に元に戻したアクションを再適用（Ctrl+Y）
- **視覚的インジケーター**: 利用可能なアクションがない場合はボタンが無効化

#### エクスポートメニュー
エクスポートボタンは複数のエクスポートオプションへのアクセスを提供します：

![エクスポートメニュー](../screenshots/export-menu.png)

- **Export DDL**: SQL データ定義言語スクリプトを生成
- **Save as Image**: 図を PNG 画像としてエクスポート
- **Export Specification**: テーブル定義書を生成
- **Save to ERD File**: ERD Designer のネイティブ形式で図を保存

### ズームコントロール

右下隅に配置：

- **ズームアウトボタン**（-）: キャンバスのズームレベルを下げる
- **ズーム率**: ズームレベルを表示し、手動で設定（25%から400%）
- **ズームインボタン**（+）: キャンバスのズームレベルを上げる

### キャンバスエリア

ERD を構築する中央のワークスペース：

- **グリッド背景**: 配置と位置合わせを支援
- **無制限の空間**: キャンバスはすべての方向に拡張可能
- **視覚的要素**: テーブル、関係、メモがここに表示
- **インタラクティブ**: すべての要素を選択、移動、編集可能

### キーボードショートカット

キャンバスインターフェースは、効率的なワークフローのためのいくつかのキーボードショートカットをサポートしています：

- **Ctrl+Z**: 最後のアクションを元に戻す
- **Ctrl+Y**: 最後のアクションをやり直す
- **Delete**: 選択した要素を削除
- **Ctrl+A**: すべての要素を選択
- **矢印キー**: 選択した要素の位置を微調整

### コンテキストメニュー

さまざまな要素を右クリックすると、コンテキスト固有のオプションが提供されます：

- **テーブル**: 編集、複製、削除、色変更
- **リレーション**: プロパティ編集、削除
- **メモ**: テキスト編集、書式変更、削除
- **キャンバス**: 一般的なキャンバスオプションへのアクセス

### ステータスインジケーター

インターフェースはさまざまな状態に対して視覚的なフィードバックを提供します：

- **選択した要素**: 選択ハンドルでハイライト表示
- **ホバー効果**: マウスが要素の上にホバーすると要素がハイライト
- **検証インジケーター**: エラーや警告の視覚的な合図
- **自動保存ステータス**: 変更が自動保存された際の表示

キャンバスインターフェースは、データベース設計のためのプロフェッショナルグレードの機能を提供しながら、直感的であるように設計されています。各ツールとメニューは、ERD 作成ワークフローの特定の目的を果たします。

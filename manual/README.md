# ERD Designer Manual

This directory contains the manual content for the ERD Designer GitHub Wiki. The manual is available in both English and Japanese versions.

## Manual Structure

The manual follows the structure specified in issue #81:

### English Version
- [Home (English)](en/Home.md) - Overview and table of contents
- [Getting Started (English)](en/Getting-Started.md) - How to start using ERD Designer
- [Canvas Interface (English)](en/Canvas-Interface.md) - Understanding the canvas and menus
- [Features Guide (English)](en/Features-Guide.md) - Detailed feature documentation

### Japanese Version
- [Home (Japanese)](ja/Home.md) - 概要と目次
- [Getting Started (Japanese)](ja/Getting-Started.md) - ERD Designerの使用開始方法
- [Canvas Interface (Japanese)](ja/Canvas-Interface.md) - キャンバスとメニューの理解
- [Features Guide (Japanese)](ja/Features-Guide.md) - 詳細な機能説明

## Usage Instructions

1. Copy the content from these markdown files to the corresponding GitHub Wiki pages
2. Upload any referenced images to the Wiki
3. Update internal links to match the Wiki page structure

## Screenshots

Screenshots referenced in the manual are stored in the `screenshots/` directory and should be uploaded to the GitHub Wiki.

This manual was created based on the actual implementation and features of ERD Designer, following the requirements specified in issue #81.

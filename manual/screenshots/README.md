## Screenshot Guidelines

When capturing screenshots:

1. **Center Positioning**: Ensure all work (tables, relations, etc.) is positioned at the center of the canvas
2. **Consistent Example**: Use the TODO application example throughout (users and todo_items tables)
3. **Clear UI Elements**: Capture clear, well-lit screenshots showing UI elements clearly
4. **Appropriate Zoom**: Use appropriate zoom level to show details while maintaining context
